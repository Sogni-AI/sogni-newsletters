Workflow Spotlight

MiniMax H3 R2V Turbo: hand it a reference, watch it recast the shot

Reference to video, in two takes, and every run is covered by Unlimited.

MiniMax H3 R2V Turbo, real phone footage plus one reference image, motion untouched.
MiniMax H3 R2V Turbo, a Krea 2 still animated, then recast with a new face on top.

Reference to video is the piece most models still get wrong. Hand MiniMax H3 R2V Turbo a clip and a reference image and it keeps the original performance, the walk, the gesture, the beat, while replacing who is in the frame. The same trick works on generated footage: render with image to video, then recast the character in a second pass.

With the Turbo build live, that loop is finally fast enough to iterate on. And because H3 is an open-weight model on the Supernet, every one of these runs is covered by Sogni Unlimited. That combination is the best reason to be on a plan right now.

Creative Agent

Stop prompting one image at a time

One brief to Sogni Creative Agent, a whole series on disk, same style in every frame.

The actual output folder: campaign subjects, typographic spots and first frames, all named and numbered.

The Sogni Creative Agent is an installable skill that gives any AI agent production-grade image, video and music generation on the Supernet. You describe the batch in plain English. It plans the run, estimates the cost up front, generates everything, and saves each result as a real named file on your disk, not a preview trapped in a chat window.

One command installs it:

Setup and install sogni.ai/skill

It runs in Claude Code, Claude Desktop and Cowork, Codex CLI, OpenClaw and any SKILL.md aware runtime, with personas and memories that follow you between them. Not a terminal person? In Cowork it shows up as the sogni-creative-agent connector, one toggle away.

The whole brief: count, one shared style, a reference image, a destination folder, aspect ratio, model.

How to prompt for a series

Tell it how many images, that they share one style, and where to save them. Attach a reference image to lock the look. It plans the batch, renders it, and leaves named files on your disk.
